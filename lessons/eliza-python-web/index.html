ELIZA가 뭘까?

1966년 만들어진 ELIZA는 심리상담사처럼 대화하는 프로그램입니다. 사실 문장을 이해하지 못하고, 입력에 특정 단어가 들어 있는지만 검사해 미리 정해 둔 문장으로 답합니다. 오늘은 그 원리를 그대로 코드로 만들어 봅니다.

최종 제출

교사용 설정 안내 (학생은 열어보지 않아도 됩니다)
  1. Google Sheet를 새로 만들고 "제출"이라는 이름의 시트를 추가합니다.
  2. 그 시트의 확장 프로그램 → Apps Script를 열고, 이 활동 폴더의 apps-script-example.gs.txt 내용을 그대로 붙여넣습니다.
  3. 배포 → 새 배포 → 유형: 웹 앱으로 배포합니다. 실행 계정은 "나", 액세스 권한은 "모든 사용자"로 설정해야 학생이 로그인 없이 제출할 수 있습니다.
  4. 배포된 웹 앱 URL(.../exec로 끝남)을 이 활동 폴더의 config.js에 있는 GAS_ENDPOINT 값에 붙여넣습니다.
  5. URL을 넣기 전까지 "최종 제출" 버튼은 비활성화되어 있고, 학생은 코드 작성·실행·대화 연습만 할 수 있습니다.
