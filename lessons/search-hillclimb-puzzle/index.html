인공지능 탐색 문제 해결 연습

수행평가 "인공지능 탐색 문제 해결"과 같은 규칙으로 8-퍼즐을 직접 풀어 봅니다. 각 단계마다 다음 상태 후보의 평가 함수값을 직접 계산해 적고, 그중 하나를 다음 상태로 선택합니다.

규칙

다음 8-퍼즐의 초기 상태에서 목표 상태까지 최상 우선 탐색(언덕 오르기)을 수행합니다. 각 단계에서 다음 상태 후보의 평가 함수값을 계산해 적고, 값이 가장 큰 상태를 다음 상태로 선택합니다.

평가 함수값은 목표 상태와 같은 위치에 놓인 숫자 타일의 개수로 하며, 빈칸은 계산하지 않습니다. 직전 상태로 되돌아가는 이동은 다음 상태 후보에서 제외합니다. 평가 함수값이 같은 경우에는 빈칸의 이동 방향을 위 → 왼쪽 → 오른쪽 → 아래 순으로 우선하여 선택합니다.

단계 1 · 언덕 오르기
단계 1

다음 상태 후보의 평가 함수값을 계산하세요

각 후보의 평가 함수값(목표와 같은 위치의 숫자 타일 개수)을 입력하고, 그중 다음 상태로 선택할 하나를 고르세요. 확인 후에는 아래 기록표에도 이동 방향과 평가 함수값을 직접 적어야 다음 단계로 넘어갈 수 있습니다.

언덕 오르기 기록표: 단계·선택한 상태·이동 방향·평가 함수값을 직접 입력하고 확인한다

더 알아보기 — 이 방법의 한계

이 방법은 "지금 당장 가장 좋아 보이는" 다음 상태만 보고 이동합니다(언덕 오르기). 직전 상태로만 돌아가지 않을 뿐, 그 전에 방문했던 다른 상태로 다시 돌아갈 수도 있고, 평가 함수값이 당장은 낮아 보여도 결국 더 빠른 길로 이어지는 상태를 놓칠 수도 있습니다. 활동 05의 최상 우선 탐색은 여러 후보를 계속 기억해 두고 그중 가장 좋은 것을 고른다는 점에서 차이가 있습니다.
