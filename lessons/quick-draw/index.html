AI는 내 그림을
어떻게 알아볼까?

제시된 사물을 그리는 동안 인공지능이 선의 모양과 그려지는 과정을 보고 무엇인지 계속 추측합니다. 잘 그리는 것이 목적이 아니라, AI가 어떤 특징을 단서로 사용하는지 관찰하며 분류 모델을 체험하는 활동입니다.

분류 모델 체험

여러 이름 중 가장 알맞은 하나를 고르는 AI

분류 모델은 입력된 데이터를 미리 정해진 여러 범주(클래스) 중 하나로 나눕니다. 퀵드로우에서는 내가 그린 손그림이 입력 데이터이고, ‘고양이’, ‘자전거’, ‘우산’ 같은 이름들이 클래스입니다.

입력 데이터내가 그리는 선

선의 위치, 방향, 모양과 그려지는 순서가 모델에 들어갑니다.

여러 클래스 중 현재 그림과 가장 비슷하다고 판단한 이름을 예측합니다.

학습과 예측은 달라요.

이 활동에서는 모델을 새로 학습시키는 것이 아니라, 이미 많은 손그림으로 학습된 분류 모델에 내 그림을 입력하고 예측 결과가 변하는 과정을 관찰합니다.

이렇게 활동하세요

  1. 제시어를 확인하고 그리기완성도보다 핵심 특징부터 빠르게 그려 보세요.
  2. AI의 추측 듣기어떤 선을 추가했을 때 정답에 가까워지는지 관찰하세요.
  3. 결과 비교하기맞힌 그림과 틀린 그림은 어떤 특징에서 달랐는지 살펴보세요.

활동 정리

AI는 그림을 ‘이해’한 걸까요?

AI는 사람이 무엇을 생각했는지 아는 것이 아니라, 많은 손그림에서 학습한 선과 모양의 패턴을 바탕으로 각 클래스일 가능성을 계산하고 가장 가능성이 높다고 판단한 범주를 출력합니다. 따라서 학습한 그림과 다른 방식으로 그리거나 구분할 특징이 충분하지 않으면 틀릴 수 있습니다. 이것이 분류 모델의 예측이며, 정답을 항상 보장하는 규칙과는 다릅니다.
