K-NEAREST NEIGHBORS

KNN

새로운 데이터와 가장 가까운 이웃 k개를 찾고, 가장 많이 나타난 클래스로 분류해 보세요. 그래프의 빈 곳을 클릭하면 분류가 시작됩니다.

굵은 테두리 점은 선택된 최근접 이웃이고, 원은 k번째 이웃까지의 거리를 나타냅니다.

데이터가 나뉘는 범주의 수입니다.
분류에 참고할 가장 가까운 데이터의 수입니다. 동률을 줄이기 위해 홀수를 사용합니다.
그래프에 생성되는 학습 데이터 전체의 수입니다.

용어를 정확히 정리해 봅시다

클래스 수
분류하려는 범주의 개수입니다.
이웃 수(k)
새 데이터를 판단할 때 참고하는 최근접 이웃의 개수입니다.
전체 데이터 수(샘플 수)
분류의 기준으로 사용되는 학습 데이터 포인트의 총개수입니다.
