기계학습 알고리즘

마트에서 잘 익은 과일을 골라주는 AI를 학습시키고 시험합니다. 어떤 정보가 판단에 도움이 되는지, 학습 자료의 구성이 결과를 어떻게 바꾸는지 차례로 확인합니다.

  • 학습과 시험학습한 판단 기준을 새로운 과일에 적용한다(활동 01)
  • 입력 정보판단에 도움이 되는 정보와 관계없는 정보를 구분한다(활동 02)
  • 학습 자료한쪽으로 치우친 자료가 판단에 미치는 영향을 확인한다(활동 03)
