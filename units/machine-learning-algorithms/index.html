활동지 05

기계학습 알고리즘

기계학습이 값을 예측하고 범주를 분류하며 비슷한 데이터를 묶는 과정을 체험합니다. 이어서 KNN과 의사결정트리가 데이터를 판단하는 방식을 직접 비교합니다.

  • 문제 유형회귀·분류·군집이 각각 어떤 결과를 만드는지 체험한다.
  • KNN가까운 이웃들의 다수결로 새로운 데이터를 분류한다.
  • 의사결정트리조건에 따라 데이터를 나누고 구간별 값으로 결과를 예측한다.
