활동지 03

인공지능의 발전 과정

직선 하나(퍼셉트론) → 선형 분리의 한계 → 규칙(마이신) → 한계 → 여러 경계와 오차 기반 학습. 인공지능이 1958~1986년 걸어온 흐름을 체험합니다.

  • 선형 분리직선 하나로 완전히 나눌 수 있는 문제인지 여부
  • AI 겨울한계에 부딪혀 연구·투자가 크게 줄어든 시기
  • 규칙 기반 시스템사람이 직접 써 둔 규칙으로만 판단하는 방식
  • 역전파여러 층을 쌓은 신경망을 학습시키는 방법

01

실습 · 보통

인공지능의 역사

퍼셉트론의 성공에서 시작해 직선 하나의 한계, 전문가 시스템(마이신)의 규칙 기반 한계를 차례로 마주하고, 여러 경계와 오차 기반 학습으로 다시 도약하기까지의 흐름을 4단계 실습으로 체험합니다.

학습 목표퍼셉트론 → 전문가 시스템(규칙 기반) → 다층 신경망과 오차 기반 학습으로 이어지는 인공지능의 발전 과정을 4단계 실습으로 체험한다.

실습 · 보통

나만의 ELIZA 만들기

사람과 대화하는 듯한 인상을 주어 큰 관심을 모았던 초기 대화 프로그램 ELIZA를 직접 만나봅니다. 파이썬으로 대화 규칙을 짜서 규칙 기반 대화형 AI를 만들고, 브라우저 터미널에서 실제로 대화하며 고쳐봅니다.

학습 목표규칙 기반(기호주의) 인공지능을 직접 만들어 보고, 활동 1에서 만난 신경망(연결주의)과 비교하며 두 접근법의 장단점을 이해한다.
