활동지 06

기계학습 알고리즘 - 군집

정답 라벨이 없는 데이터를 비슷한 특성끼리 묶고, 만들어진 고객 집단을 해석해 실제 마케팅 전략으로 연결합니다.

  • K-means가까운 중심점에 데이터를 배정하고 중심을 반복해서 이동한다.
  • 실루엣 계수같은 군집은 가깝고 다른 군집은 잘 떨어졌는지 비교한다.
  • 군집 해석번호가 아니라 데이터 특징을 근거로 집단의 의미를 설명한다.

실습 · 보통

K-means로 고객 집단 찾기

K-means의 반복 과정을 체험한 뒤 Orange3에서 K=2~6을 비교하고, 선택한 군집 수에 맞춰 고객 특성과 마케팅 전략을 작성합니다.

학습 목표실루엣 계수와 해석 가능성을 함께 고려해 군집 수를 선택하고 군집별 전략을 근거와 함께 제안한다.
