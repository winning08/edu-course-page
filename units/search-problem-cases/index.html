탐색의 다양한 문제 해결 사례

상대가 있는 게임에서 컴퓨터와 틱택토를 직접 두어 보고, 컴퓨터가 나와 상대의 가능한 수를 함께 살펴 최선의 수를 고르는 Min-Max 탐색 과정을 의사결정 트리로 직접 따라가 봅니다.

  • 게임 트리 탐색나와 상대의 가능한 수를 함께 살펴본다(활동 01)
  • Min-Max 의사결정 트리후보 수, MAX/MIN의 차례, 말단 점수가 아래에서 위로 전달되어 최종 선택이 만들어지는 과정을 확인한다(활동 01)

게임 트리 탐색

Min-Max 알고리즘을 적용한 컴퓨터와 틱택토를 하고, 게임이 끝난 뒤 컴퓨터가 상대의 최선 대응까지 살펴 수를 고른 과정을 의사결정 트리로 직접 따라갑니다.

학습 목표상대가 있는 게임에서 인공지능이 가능한 상태를 탐색해 수를 선택하는 원리를, Min-Max 의사결정 트리를 직접 따라가며 체험한다.
