활동지 03

인공지능과 탐색

우리는 잘 모르는 곳에 갈 때 지도 앱으로 길을 검색합니다. 지도 앱은 어떻게 가장 좋은 길을 찾아낼까요? 늑대·양·양배추 강 건너기와 8-퍼즐로 상태·간선과 너비 우선 탐색(BFS)을 몸으로 먼저 익힌 뒤, 학교 배달 로봇이 정문에서 매점까지 가는 같은 지도 위에서 균일 비용 탐색 → A* 탐색 순서로 로봇이 다음에 어느 칸을 열어볼지 직접 예측하고 확인합니다.

  • 상태·행동강 건너기를 직접 조작하며 문제의 순간과 가능한 이동을 구분한다(활동 01)
  • 맹목적 탐색8-퍼즐을 직접 맞춘 뒤 너비 우선 탐색이 상태를 층별로 넓히는 과정을 관찰한다(활동 02)
  • 비용 탐색이동 비용이 다를 때 가장 싼 경로를 찾는다(활동 03)
  • 지능적 탐색휴리스틱값을 이용하는 A* 탐색과 앞선 방법을 비교한다(활동 04)
  • 최상 우선 탐색h(n)만 보고 다음 상태를 고르는 탐색이 g(n)을 함께 보는 A*와 어떻게 다른지 8-퍼즐로 확인한다(활동 05)
  • 언덕 오르기수행평가와 같은 규칙으로 평가 함수값을 직접 계산하며 8-퍼즐을 풀어 본다(활동 06)

01

실습 · 입문

강 건너기로 만나는 탐색

늑대·양·양배추를 배에 직접 태워 옮기며 상태·행동·초기 상태·목표 상태를 몸으로 익힙니다.

학습 목표강 건너기를 직접 조작하며 탐색 문제를 상태와 행동의 연속으로 표현한다.

02

관찰 · 입문

8-퍼즐로 보는 맹목적 탐색

8-퍼즐을 직접 맞춰 본 뒤, BFS가 가까운 상태부터 층별로 넓히고 이미 본 상태를 제외하는 과정을 확인합니다.

학습 목표BFS가 최소 이동 경로를 찾는 과정과 중복 상태를 제외하는 이유를 설명한다.

03

실습 · 보통

눈이 내리면? 가장 싼 길 찾기

같은 지도에 눈이 쌓여 칸마다 이동 비용이 달라집니다. 균일 비용 탐색이 지금까지 든 비용 g(n)이 가장 작은 칸부터 넓혀가며 실제로 가장 싼 길을 찾는 과정을 예측합니다.

학습 목표칸마다 이동 비용이 다를 때, 균일 비용 탐색이 지금까지 든 비용 g(n)이 가장 작은 곳부터 넓혀가며 실제로 가장 싼 경로를 찾는다는 것을 체험한다.

04

실습 · 보통

목표를 어림짐작하기: A* 탐색

목표까지 남은 거리를 어림짐작한 휴리스틱 h(n)을 더한 f(n)=g(n)+h(n) 기준으로 A*가 더 적은 칸을 열어보고도 최적 경로를 찾는 것을 확인하고, 세 알고리즘의 완전성·최적성·효율을 비교합니다.

실습 · 보통

목표만 보고 판단하면? 최상 우선 탐색

같은 8-퍼즐의 새로운 문제를 목표까지 남은 거리 h(n)만 보고 풉니다. g(n)을 아예 보지 않는 최상 우선 탐색이 왜 최적성을 보장하지 못하는지 확인합니다.

학습 목표목표까지 남은 거리를 어림짐작한 휴리스틱 h(n)만 보고 다음 상태를 고르는 최상 우선 탐색을 8-퍼즐로 체험하고, g(n)을 보지 않아 최적성을 보장하지 못한다는 한계를 이해한다.

연습 · 보통

인공지능 탐색 문제 해결 연습

수행평가 "인공지능 탐색 문제 해결"과 같은 규칙으로, 후보 상태마다 평가 함수값을 직접 계산해 적고 다음 상태를 골라 봅니다.

학습 목표수행평가 '인공지능 탐색 문제 해결'과 같은 규칙(일치 타일 개수 평가 함수, 직전 상태 제외, 방향 우선순위)으로 8-퍼즐 언덕 오르기를 단계별로 직접 계산해 본다.
