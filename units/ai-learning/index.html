활동지 03

AI는 어떻게 학습할까?

세 활동은 같은 마트 과일 선별 AI를 소재로 이어지는 하나의 학습 순서입니다. 활동 01에서 색깔·촉감 같은 입력 정보로 AI를 학습시키고, 활동 02에서 관계없는 정보를 가려내고, 활동 03에서 치우친 학습 자료의 한계를 확인합니다. 순서대로 진행하는 것을 권장하지만, 각 활동은 독립된 페이지이므로 원하는 활동을 바로 열어도 됩니다.

  • 입력 정보AI가 판단에 사용하는 정보(활동 01)
  • 노이즈판단과 관계없는 정보(활동 02)
  • 편향된 데이터한쪽으로 치우친 학습 자료(활동 03)

AI는 어떻게 판단할까?

3개 활동
01

실습 · 보통

잘 익은 과일 찾기

마트의 과일 선별 AI를 훈련시키는 임무를 맡아, 과일 12개로 AI를 학습시키고 같은 판단 규칙을 다른 과일 5개에 한 화면에서 동시에 적용해 시험까지 치러보며 어떤 정보가 판단에 진짜 도움이 되는지 직접 찾아봅니다.

학습 목표색깔·촉감 같은 입력 정보로 AI를 학습시키고, 같은 판단 규칙을 다른 과일에 적용해 시험해 본다.

02

실습 · 입문

정보가 많으면 더 정확할까?

같은 마트 AI에 계절 정보를 하나 더 알려주고, 학습 결과를 비교해 어떤 정보가 진짜 판단에 도움이 되고 어떤 정보는 관계가 없는지 직접 찾아봅니다.

학습 목표판단과 관계없는 정보(노이즈)를 가려내며, 정보가 많다고 항상 도움이 되지는 않는다는 것을 확인한다.

03

실습 · 입문

학습 자료가 한쪽으로 치우치면?

일부 과일로만 학습한 마트 AI가 처음 보는 과일도 잘 판단하는지 시험해 보며, 다양하고 고른 학습 자료가 왜 필요한지 직접 확인합니다.

학습 목표치우친 학습 자료로 학습한 AI의 한계를 시험해 보고 편향된 데이터 개념을 이해한다.
