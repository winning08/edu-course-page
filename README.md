# AI 추론 실험실

고등학교 정보·인공지능 수업용 체험 페이지 프로젝트입니다.

첫 번째 수업은 과일의 색깔·촉감·계절을 보고 익음 여부를 예측하는 15라운드 분류 게임입니다. 학생은 정답 규칙을 미리 배우지 않고, 반복되는 예측과 피드백 기록을 비교하며 분류에 유용한 정보와 무관한 정보를 스스로 발견합니다.

## 실행

```bash
npm install
npm run dev
```

검증 빌드는 `npm run build`로 실행합니다.

## 주요 파일

- `app/ripeness-game.tsx`: 게임 상태, 랜덤 라운드, 숨은 판정 규칙
- `app/globals.css`: 청과물 시세표 칠판 디자인과 반응형·접근성 스타일
- `app/page.tsx`: 첫 번째 수업 페이지 진입점
