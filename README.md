# 고등학교 정보·인공지능 수업 자료

여러 수업 자료를 독립 웹페이지로 제작하고 GitHub Pages에서 제공하기 위한 프로젝트입니다.

## 구조

- `index.html`: 전체 수업 자료 허브
- `data/lessons.json`: 허브에서 사용하는 수업 목록
- `lessons/`: 차시별 독립 웹페이지
- `tests/`: 수업 로직과 정적 페이지 구조를 확인하는 테스트 하네스

## 첫 번째 수업

`lessons/ai-inference-ripeness/`는 과일의 색깔·촉감·계절을 보고 익음 여부를 예측하는 15라운드 분류 실험입니다. 학생은 점수나 정답 규칙을 배우지 않고 반복되는 피드백을 비교하며 신호와 노이즈를 발견합니다.

## 로컬 확인

```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 엽니다. 테스트는 `npm test`로 실행합니다.
